The Azure extension adds inventory discovery, architecture interviewing, and
intended-design review to the standard Spec Kit lifecycle.

1. Constitution
2. Azure Inventory Discovery (optional)
3. Azure Interview
4. Intended Design Review
5. Specify
6. Clarify (optional)
7. Plan
8. Checklist (optional)
9. Tasks
10. Analyze (recommended)
11. Implement
12. Converge until complete

## Control boundaries

Inventory evidence remains `unconfirmed` until reconciled during the interview.

The intended design remains `intended` and `unreviewed` until explicit human
approval.

Neither artifact proves deployed Azure state.
